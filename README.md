# 💱 Currency Converter App

A modern and responsive currency converter web application built using **React**, **Vite**, and **Tailwind CSS**. It fetches real-time exchange rates and allows users to convert between different currencies seamlessly.

![screenshot](https://images.pexels.com/photos/14268860/pexels-photo-14268860.jpeg?auto=compress&cs=tinysrgb&w=1260&h=750&dpr=2)

---

## 🚀 Tech Stack

| Technology | Description |
|------------|-------------|
| ⚛️ React     | UI Library for building user interfaces |
| ⚡ Vite      | Fast build tool and development server |
| 🎣 React Hooks | For managing state and side effects |
| 🎨 Tailwind CSS | Utility-first CSS framework |
| 🌐 ExchangeRate API | To fetch real-time currency data |
| ☁️ Netlify   | Deployment and hosting platform |
| 🗃️ Git & GitHub | Version control and code hosting |

---

## 🔧 Features

- 🌐 Real-time exchange rates
- 🔁 Currency conversion between any two currencies
- 🔄 Swap currency functionality
- ✨ Blurred glass UI design
- 🔥 Custom React Hook (`useCurrencyInfo`) for fetching rates
- 📱 Fully responsive layout
